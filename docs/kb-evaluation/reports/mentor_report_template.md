# Cordys CRM 知识库检索与问答评测报告

状态为模板，结果待人工金标与真实实验完成后填写。评测版本、日期、负责人和复核人待填写。

## 目标与对象

说明六份跨时期 PRD 的知识库范围、版本限制，以及检索与问答的研究问题。

## 语料与金标

列出文档哈希、文字/图表规模、缺失范围、产品版本、开发及留出划分。说明标注人数、独立试标、仲裁及一致性。官方手册仅用于核对，独有规则及冲突单列。

## 实验协议

列出代码和依赖环境、模型及向量空间、配置、快照、提示词版本、缓存、预算和计时口径。登记主指标、k、相关度、重叠阈值、零分母、失败与未知样本口径。

## 结果与配置对照

按题目类别展示 Recall、Hit、MRR、Precision、完整证据命中及可计算的 nDCG。问答展示人工忠实性、引用、完整性、正确性与拒答 P/R。每项附有效样本数、聚类数和区间，失败率单列。

比较单文档与全库干扰、分块、关键词及重排；配对差值绑定相同问题和协议。模型调用数、usage 与时延另表，不将离线 Fake 结果用作业务质量。

## 失败归因与局限

记录未解析、未召回、排名靠后、截断、未用证据、矛盾、误拒及未拒答等案例，展示问题、原文、候选和实际回答。说明跨时期版本冲突、小样本、人工偏差和公开资料污染的影响。

## 结论与复现

仅在真实实验和人工审核后填写默认配置建议及适用范围。附运行清单、逐题结果、脱敏配置、金标版本和命令。问答结论不能直接代替测试用例生成质量结论。
