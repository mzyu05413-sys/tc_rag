## 5. R3 指标正确性验证

记 C 为覆盖必要证据的候选数，U 为去重覆盖证据单元数，G 为必要证据总数。每题 P=C/k，R=U/G，F1 为 P/R 的调和平均。宏 F1 对每题 F1 取平均；微 P=sum(C)/sum(k)，微 R=sum(U)/sum(G)，微 F1 由微 P/R 计算。

该 F1 综合候选与证据两种粒度，不共用一个 TP 构造分类式混淆矩阵。
