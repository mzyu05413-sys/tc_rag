# 检索评测改进协议 v2

日期：2026-11-15。依据用户最新要求，优先解决样本不足和指标口径，再评估BM25与rerank。本协议优先于旧方案中已过时的混合粒度F1、样本数量和实验顺序。本文是开发安排，不代表新功能已经实现。

## 1. 先做什么

1. 扩大审批流问题集并冻结片段相关性规范。
2. 完成标准混淆矩阵、宏微汇总、多k及排序指标运行器。
3. 对照现有词频、BM25、向量与RRF混合。
4. 固定候选池后评估rerank。
5. 再开展R2后端与相似度性能实验。

## 2. 样本扩展

目标先达到30道可回答题，覆盖精确字段/术语、语义改写、条件/例外、多规则联合等类型，尽量分散业务章节。30题是可执行的试点目标，不是统计充分性保证，不为凑数编造需求或重复换词。

已有5题及其改写均固定归dev，不进入test。按query_family分组，目标dev/test各约15题；同规则/同答案的改写不跨集合，不承诺恰好15/15优先于隔离要求。以独立业务规则族数量而非题数衡量多样性。发现某题无答案或规则冲突则单列，不混入主检索评分。

当前仍限定审批流150片段，便于保持实验可比。扩展其他模块作为后续独立实验，不悄悄扩大现有查询范围。新增查询向量由用户显式采集，不重跑文档和图片。

## 3. 片段金标规范

针对每道问题标注完整150片段：相关=直接提供所问规则或明确子场景的可用正文依据；仅话题一致为不相关；相关不等于足以完整作答。Vision与作废内容按当前正文范围排除，混合来源只判断有效正文。

新增问题先定义所问规则与适用范围，再标全库，标注不能依据某个模式的返回结果反推。助手预标保留理由、未知与来源，用户采纳后版本化发布，不伪造第二人独立审核。现有750标签可复用，不因扩题直接覆盖。增加部分支持的borderline示例以统一尺度。

## 4. 指标必须同粒度

全集为每题固定150片段，返回集合为前k。TP/FP/FN/TN全部按片段计数；重复ID或范围外ID为格式错误。P=TP/(TP+FP)，R=TP/(TP+FN)，F1=2TP/(2TP+FP+FN)，Acc=(TP+TN)/N。

宏平均逐题计算后平均；微平均先累加四数再算。报告有效n及失败/未知/无答案排除数量。零分母记null；无相关返回但实际有返回时P=0，有相关标签但无返回时R=0。P分母是实际返回数，不将不足k的空位计为FP；另记returned_count和missing_slots，避免与旧C/k定义混淆。

主报告：P/R/F1@5、@10，MRR@10；多k附表：1/3/5/10/20。Accuracy辅助，不用于配置选择。二元相关标注完整后可补二元nDCG@10，独立说明理想排序及零正例处理，不套用旧事实级nDCG。事实覆盖作为可选独立维度，不参与标准F1。

只在dev选择参数及k，test冻结后一次验证；开发期五题指标没有显著性或泛化保证。各模式使用同一有效题集，未知/服务错误不得填成正确结果。

## 5. k与召回预算分开

当前k=5是最终返回数量，不是仅检索5条。原每路预算20；已有探索运行40。先固定每路预算40，评估最终k=1/3/5/10/20，所有模式同预算。另保留20/40预算消融，不混淆“候选更大”与“排序更好”。

5是否过小由R@5到R@10/20曲线判断，不先认定。增加k往往带来精确率、上下文长度和重排成本的取舍，不能仅比较Recall宣称更优；还要看是否因长片段截断失去有效规则。本轮不自行指定最终业务通过阈值。

## 6. BM25实验

保留jieba分词，新增BM25评分，旧TF实现作为基线。对照：vector、TF、BM25、vector+TF的RRF、vector+BM25的RRF。分词、词表及标点过滤规则必须一致并记录版本，避免把清洗变化当BM25收益。

BM25复用或新增可选适配器，经ports/bootstrap装配，不复制到多处。登记具体实现、k1/b、IDF公式及统计语料范围（本轮固定150片段）；默认参数不冒称最优。共用快照、查询向量、预算与k，不改变旧生成入口默认语义。不自动安装依赖或调用付费服务。

## 7. rerank独立实验

先冻结vector+BM25融合后的40条候选，再比较重排前后同一候选集合的排名；不得同时更换召回或扩大池子。报告MRR/nDCG、P/R@k、候选池Recall、时延和降级。候选池外的漏召回无法由rerank修复。

模型选择、候选截断和提示词/版本单独登记；本地离线可用Fake验证编排。真实模型调用由用户显式启动，成本与耗时单列。旧RAG及kb默认重排设置不因实验自动变更。

## 9. 用户补充：官方文档驱动问题及标签

问题与参考答案优先从两份用户指定官方手册独立抽取，而不是按某个检索模式的返回结果编题。保存URL、章节、访问日期、原文依据、原子答案和query_family；网页当前为动态页面，后续正式冻结需保存可核查的页面材料及指纹，不能仅凭URL宣称版本冻结。

流程：官方规则→独立问题/参考答案→当前PRD版本对应核对→当前快照Block/Chunk映射→全范围片段相关性预标→异常项复核→用户批量采纳→冻结标签。可以自动定位和预标，但未映射成功不能一律标负例；保留未知，剔除规则必须预登记并报告数量。官方新增删除需求继续排除当前旧PRD评分。

标签保留assistant_official_reference来源，不伪装独立人工标注。仅把来源冲突、示例/默认值混淆、语义映射不确定项集中交用户确认，明确项不要求用户重写。正式集合只纳入已采纳且范围完整题。30题现有草稿为PRD驱动，保留历史；后续应独立生成官方驱动版本，不将旧草稿回填网址冒充官方抽取。

关键词与向量使用同一快照、同一chunk_id和范围，索引结构各自独立：向量为矩阵/向量索引；当前TF为chunk_id到Counter的映射，并非标准倒排索引。新增BM25适配器必须明确其实际索引结构，不能未实现就宣称已持久化倒排索引。二者的结果通过chunk_id关联并按RRF融合。
