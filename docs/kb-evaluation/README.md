## 用户文档目录与终端交互

六份 PRD 的导入目录为 workdir/kb/sources/cordys，冻结语料与金标放 workdir/kb/evaluation。原始外部文件保留原路径，显式导入后才发布新知识库快照。

实际命令为 kb ingest、list、search、ask、chat、batch、evaluate 和 compare。首次 ingest 自动建立发布记录，无需单独 create。联网命令省略 --live 时仅预览。具体参数和金标格式以[使用说明](usage.md)为准。

终端展示入库快照与文档，检索返回片段、来源和分数，问答返回带引用的声明或拒答原因。批量评测输出逐题结果、运行清单以及评分 JSON/Markdown，最终报告依赖人工审核与真实实验。
