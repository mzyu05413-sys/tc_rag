# 新留出问题的来源与边界

官方手册是业务核对来源，PRD及当前快照才决定检索可获得的证据。手册未介绍某个细则，不代表PRD错误；手册独有的新能力也不能直接变成旧知识库必须答对的问题。

候选题的正文锚点只能说明至少存在一份依据，不能据此将其余463片段全部判负。完整相关集合未审查前，Recall和F1不能作为正式结论。

不同问题若共享正例片段或同一规则，不能被视作独立业务样本。跨模块也可能有同义规则，文档不同不自动保证隔离。当前10题锚点组未重叠，后续仍须检查完整相关集合。

全库463片段与旧审批流150片段是不同实验范围；新对照需要让各方法同时使用相同范围，不能拿两轮平均值直接判断优化收益。固定旧快照中的新问题只能支持已见语料内验证，不等于对新文档的泛化。
