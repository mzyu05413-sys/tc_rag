# 功能任务第一阶段记录

一个功能任务可以需要多条规则，规则还可能有多个替代证据。先写范围和必要规则，再独立检查检索结果，能避免根据命中片段反推答案。

本轮3项功能共16条草稿规则、21处来源锚点。锚点存在只证明有候选依据，不证明相关集合完整；待确认的数值边界和权限关系不能默认确定。片段P/R与规则覆盖分开统计。

检索候选、预算后输入、模型结果是三个位置。此次记录预算后应用层证据，并区分已有核心证据与额外检索。缓存结果虽可交付，不代表本次远端调用；模型调用完成也不代表业务正确。

原有问答评分150片段是一次实验的约定，不应成为通用工具的固定条件。新范围需显式列出ID并与标签全集完全核对，未知不当负例，零正例的Recall/MRR保持null。

当前只完成材料准备、观察能力和评分边界，未优化功能归并或改变默认检索。后续根据“原文→提炼规则→实际上下文→测试点/用例”的丢失位置选择整改项。
