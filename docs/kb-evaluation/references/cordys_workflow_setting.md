# Cordys CRM 流程设置

官方来源：[流程设置](https://docs.fit2cloud.com/cordys/user_manual/workflow_setting/)  
整理日期：2026-11-10。用途：审批流 PRD 对齐参考。根据此前可检索的官方页面内容整理。

| 核对主题 | 手册要点 |
|---|---|
| 入口 | 管理员从「系统 → 流程设置」进入审批流列表。 |
| 适用对象 | 手册列举订单、发票、合同、报价等业务单据，并说明系统提供预置审批流。 |
| 流程管理 | 列表可查看启用状态和执行时机。每个流程具有唯一标识。 |
| 触发条件 | 将业务对象、流程启用状态与执行时机一起核对。手册列举创建、编辑和删除，具体场景需按业务对象与版本确认。 |
| 配置分工 | 基本信息决定流程适用范围，流程设计与更多设置定义节点及附加规则。 |
