## 学习要点

### 真实五题离线候选运行

用户已自行执行查询向量采集，助手确认文件存在后运行 run_modes.py。材料指纹、问题文字、空间和完整索引版本校验通过，结果写入 workdir/kb/evaluation/retrieval_pilot/runs/R1/five_questions_v1。5题×3模式=15组结果，每组5条，无空结果；向量与混合 top5 集合重合数依题为4、3、3、3、2。集合变化不等于质量提升。已生成候选阅读稿和数量摘要；formal_metrics 全部保持 null。本次候选运行无模型调用，未完成语义审核、正式金标完整性核验及 Recall 计分。

### 查询向量采集交付

新增 collect_queries.py：默认预览不装配模型，--live 复用 build_kb_ingestion 的 embedding 和缓存，仅调用 embed_batch，不执行 ingest 或 Vision。校验空间、冻结快照及返回矩阵，输出拒绝覆盖，provider 在 finally 关闭。13 项相关离线测试通过、采集入口 Ruff 通过；本机真实配置的默认预览通过（5题、2048维），未发真实请求。测试覆盖向量异常及已有输出保护，尚未验证真实供应商返回、收费、网络失败与重试行为。正式金标与 R1 实测仍待完成。

### R1 首版候选运行入口

新增 eval/kb/run_modes.py，仅组合现有 NumpyIndex、KeywordIndex 和 RRF，不修改生产流程。提供材料哈希、查询文字/空间/快照、矩阵行序与完整索引版本校验；候选排名、分数和耗时落盘，不输出正式指标。11 项相关离线测试通过，新增入口及测试 Ruff 通过；真实中文依赖 jieba 当前未安装，尚未跑真实五题。查询缓存核查见材料目录 query_cache_audit.json。未调用模型。

仍待补齐：环境/库版本自动登记、关键词原始分数（现有组件不提供）、输出的来源字段向评分契约转换、原子化完整金标与真实查询向量。因此入口是候选运行首版，不是完整 R1 验收。
