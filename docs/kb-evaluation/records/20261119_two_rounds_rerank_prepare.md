# 两批功能任务重排对照准备完成

用户调整顺序：先给前两批功能任务增加重排前后对照，观察指标，再考虑调参；独立功能验证准备暂后置，不继续扫描RRF权重。RAG主线、阈值与性能继续暂停。

冻结四组：首批三功能的纯向量、混合1∶1；补充三功能的纯向量、混合1∶1。每组3题，共12个查询—候选池组合。每题候选分别14/27/40或14/40/27，总计324个候选处理项，不代表实际HTTP请求次数；供应商可能分批、重试。

只在每组内部比较固定池重排前后，观察k=3/5/10。每题保留原始候选ID、文本和顺序，最大40；不同检索方法的池可以不同，不能将跨方法差异全部归因于重排。池外证据不可能靠重排补回。输入为原冻结片段文本（含图文来源），不同时做正文投影或文本清理。默认模型名取当前配置并登记，真实运行时校验；精确同分保留输入顺序input_order，关闭其他调参。

两批分表：首批沿用正文金标`gold_v1`（182标签），补充批次沿用图文金标`expansion_multimodal_gold_v1`（97标签）。不能合并成一个总体P/R/F1，也不把首批未经审核图片自动算正。必要正文规则完整覆盖另外评分；服务错误单列，不填0或视为正确。

私有计划：`workdir/kb/evaluation/feature_pilot/datasets/two_rounds_rerank_v1/plan.json`，四个子目录各有`pool.json`，登记源文件、候选池SHA256与批次金标路径。真实输出拟放`runs/two_rounds_rerank_v1`，当前未执行、无重排后分数。
