# 开发集重排输入对照：全文与直接正文

## 设置与完整性

用户执行真实采集，助手离线评分。固定原快照、dev11题、每题40个候选ID及原始次序、来源和同一版正文相关性金标；仅替换交给rerank的候选文字。直接正文输入从Block来源区间回读，排除Vision解释；没有直接正文的候选以版本化占位符代替，候选仍保留。

11题全部成功，0题服务错误。候选集合/顺序、问题文字、快照、金标哈希检查通过；返回分数均按降序排列。新旧采集均记录模型别名`rerank`，未保存可证明远端权重和服务版本完全相同的指纹，因此结果按本轮来源输入策略对照解释。未重新入库、识别图片或采集embedding。

## 排序变化与剩余问题

- 原全文重排的前1中，无直接正文候选出现4/11次，前5中出现29/55次；正文输入占位策略下两项均为0。该现象支持“输入来源策略与正文金标存在错位”的诊断，但不能单独证明Vision内容本身错误；占位符同时改变了长度和内容。
- 相比原全文重排，4题新增前5命中，无题减少前5命中。
- 相比不重排，2题从未命中变为命中，1题从2条命中降为0条；首条相关排名6题改善、3题下降、2题不变。
- `official_approval_39`的两个相关片段由第1/3名降至17/16名，导致前5完全漏掉。一个片段较长、另一个较短，不能仅凭这一个案例认定长度偏差为唯一原因。此题在k=20才全部找回，需单独研究列表操作类问题与证据表达。

后续离线核查发现，这两个片段与前排15条同为1.0分，排名受同分次序影响；不能将第16/17名视为模型明确打出更低分。详见[同分归因与反事实对照](20261116_rerank_tie_diagnosis.md)，保留本页原实测指标不覆盖。

## 结论与状态

来源输入策略调整在本批dev上恢复了重排召回并改善首条证据排名，当前证据不足以认定rerank普遍无效；之前的“关闭当前全文重排”结论仍适用于旧配置。正文策略仅为开发期候选方案，尚未获得新的独立留出验证，不切换生产默认配置。

精确率低、多规则证据遗漏及个别题排序退化仍存在。下一步先离线分析39题退化原因及来源表达，保留k=5主指标、多k辅助；策略冻结后另建未参与分析的新留出问题。原test已用于补充对照，不能再充当本策略的独立验证集。

本实验沿用旧快照，不包含本轮删除线解析修复，不能将改善归功于删除线过滤。
