输入线索：该搜索候选未带所属跟进计划标题，却包含下个小节负责人标题。混合重排第3候选289字，来源仅38字正文关联复述和251字Vision不确定项，无可见事实，却得到1.0；相邻跟进记录正文、概览等也高分。另一正确短校验片段34字同样1.0，故不将长文本或图片单独定为根因。
