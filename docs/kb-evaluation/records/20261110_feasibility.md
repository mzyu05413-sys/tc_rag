# 知识库测评可行性与启动记录

## 实验范围

| 项目 | 首期处理 |
|---|---|
| X1 度量与归一化、X2 后端 | 先用固定向量验证排序方向、并列、范围过滤、ID 映射和等价性，再测延迟。单位向量下余弦、内积和平方 L2 排序等价，允许浮点误差。 |

## 冻结前修订

- 多份文档组成评测集，每次仍限定单份文档。近重复文档及同文档不同版本放同一划分。以文档为配对统计单位，文档过少时报告逐文档差异和样本数。
- 用文档哈希、冻结的解析文本、Block 锚点与半开字符区间建立金标。保留章节和引文供回查，图片事实绑定图片位置。先验证候选能回映到坐标，再启动正式标注。
- Recall@k 用前 k 个候选覆盖的去重金标区间数除以全部相关区间数。Precision@k 以命中候选数除以固定 k。明确 nDCG 的候选增益和重复证据处理。严格重叠比例以金标区间长度作分母。无相关证据查询单独统计。
- 规则语义匹配先判等价和证据，再判类型。T4 报告匹配规则上的分类结果及匹配样本数，T3 单列漏提与多提。用例分别报告结构引用覆盖、人工断言覆盖及预期的证据支持。
- 提炼先于检索。因此后置检索配置主要影响测试点与用例，提炼质量单列评测。比较后置检索因素时固定可复用的上游结果，并记录模型重复运行与缓存口径。
- 确认已有运行快照能否导出逐查询候选、来源区间、名次和耗时。缺失字段再补只读采集。费用只在有用量和可核验单价时估算。

## 执行与留档

| 阶段 | 退出条件 | 产物 |
|---|---|---|
| S0 协议 | 确认语料授权与外发范围、标注人力、样本下限、主指标及阈值 | 评测协议、决策记录 |
| S1–S2 冒烟 | 选一份脱敏 PDF 或 DOCX，约 20 条规则试标。跑通引文回查、检索评分及一条规则到断言的追溯 | 清单、划分、标注指南、试标笔记、冒烟记录 |
| S3–S5 正式开发集 | 双人独立标注、仲裁并冻结。完成前置检查，运行基线和优先对照 | 冻结金标、一致性记录、运行清单、指标及失败案例 |
| S6 留出集 | 冻结 B0/B* 与评分协议后，在留出文档做一次最终验证 | 导师报告、复现附录 |

仓库 docs 保存协议、决策和可公开报告。私有语料、标注、实验日志放在受控的 workdir/dev/eval 下，写入前检查忽略规则。每次运行记录文档和金标版本、提交号、提示词与模型版本、脱敏配置、缓存状态、运行 ID、样本数及异常。导师报告按语料与标注质量、分环节结果、端到端对照、可追溯失败案例、推荐配置与局限组织。
