目标 C04 为新建审批流字段表，含第1～3题关键规则。审批流范围共150个 Chunk，目标确实在范围内。

因此第2、3题在当前预算内漏掉目标不是范围过滤或目标不在库；目标向量排名位于预算之外。第1题向量命中后融合落到第7名，属于最终排序损失。不能将扩大预算后找到规则算作原配置成功。

现有关键词算法对 query 分词去重后，累加候选中这些词的词频，过滤空白但没有过滤标点。三题的目标词项命中均含逗号（次数3）。这是已核对的计分行为；长片段及泛化词可能影响排名，但尚未做消融，不能宣称已证明唯一原因。关键词不是 BM25。
