# 知识库终端表现统一

用户要求自行操作模型启动，开发只处理终端显示和离线验证。本轮未调用真实模型。

复用原 RAG 的 TerminalProgress 和 format_duration，知识库应用只发送已有 ProgressEvent 类型，显示回调继续作为旁路。配置摘要不展示密钥或完整端点。阶段显示覆盖文档处理、Vision、向量索引、发布、召回、重排和回答，实际执行的阶段才编号。

新增 kb start 交互工作台，真实终端运行 kb 无子命令也可进入预览工作台，非交互环境显示帮助。默认预览保持原来的显式 --live 约定，用户自行启动真实模型。

search 与 ask 默认显示可读内容、编号来源及耗时，--json 保留机器可读标准输出，进度和保存位置写标准错误。--quiet 隐藏阶段信息。chat 支持 /sources、/new、/exit 及输入中断；每题独立的检索与回答语义保持不变。

CLI 离线测试覆盖菜单不装配模型、回答及引用可读、JSON 标准输出隔离。完整回归 821 passed、2 skipped；Ruff 全仓与 Mypy 113 源文件通过。随后评测摘要及中断提示调整经 6 项 CLI 定向复测通过，最终小范围终端复测另行执行。
