# 阶段 3a · 仅向量检索首批

新增 SearchService 和 kb search。每次开始固定当前发布快照，检查格式、空间与度量，加载并校验原索引，然后查询 embedding 与搜索。不调用回答模型。可以限定逻辑文档，未知成员拒绝，空集合返回空候选且不调用 embedding。

输出包含候选排名、原始分数及类型、原文、Block 区间、位置、文档版本和分阶段耗时。CLI 保存 JSON 阅读产物。当前仅支持活跃快照，暂不支持历史快照查询；关键词与重排启用时明确拒绝，完整指标评分、SQLite 查询事实记录和配置运行清单仍待补齐。不能把当前结果保存形式当作全部追溯契约已验收。

真实入库与查询仍需用户显式 --live，本轮未调用真实服务。Fake 测试覆盖范围过滤、来源映射、空范围、陈旧快照、坏索引及查询前拒绝。工程离线测试不表示检索语义效果通过。

人工金标步骤见 ../annotation_guide.md，首批仅审批流文档试标。标注范围扩大到六份全库时重新检查证据完整性。
