# 知识库工程链路离线交付

日期：2026-11-12。使用说明见 ../usage.md。早期记录保留当时的范围，当前状态以本记录与执行计划为准。

## 实现范围

- 入库复用 PDF/DOCX、配置分块、可选 Vision、批量 embedding 和 NumPy/FAISS。跨时期产品版本可由 --versions 清单登记。
- embedding 缓存按空间与文本身份隔离，校验维度、有限值与指纹。并发缓存写入复用数据库中已确定的向量。
- 历史快照、文档过滤、关键词融合、HTTP 重排与失败降级可用；候选保留各阶段分数、文件标识、业务版本、原始 Block 与 Vision 来源。
- 问答记录实际证据、预算裁剪、逐声明引文、拒答与服务错误。逐字引文校验不代替人工语义审查。
- search、ask、chat、batch、evaluate、compare 和 list 入口可用。联网命令默认预览，显式 --live 才请求模型。
- 查询、回答与批次映射写入独立 SQLite，JSON/Markdown 为派生阅读与评分产物。清单逐字段白名单记录非凭据参数及代码、提示词指纹。
- 离线检索评分处理证据去重、未知与失败、MRR、Precision、可计算的 nDCG；人工回答评分处理正确性、支持性、引用、完整性和拒答。按问题族给出 bootstrap 区间，配置对照为配对差值。
- 原生成固定基线覆盖原文、区间、float32 小端向量哈希、排名、最终用例语义及引用关系；只对固定虚构夹具成立。

自动审核曾拦截完整配置清单补丁，已替换为明确字段白名单，并用虚构凭据标记验证排除密钥、环境变量名及完整端点。
