# P0：基础契约

[返回学习导航](../README.md)

P0 为唯一 RAG 流程提供配置、领域对象、身份与指纹、计时和离线替身。基础能力已实现；真实业务金标与语义质量需人工维护和验收。

| 指南步骤 | 学习重点 |
|---|---|
| 0.1 仓库骨架 | 分层、依赖及中文协作约定 |
| 0.2 配置 | 文件选择、覆盖顺序、校验与凭据引用 |
| 0.3 领域契约 | 原文、证据、规则、测试点、用例、审核和 ID/指纹 |
| 0.4 计时 | 同步/异步、异常/取消、上下文隔离、累计与墙钟 |
| 0.5 样例与标注 | JSONL、虚构样例、人工金标和私有资料边界 |
| 0.6 CLI 与替身 | 计划预览、正式装配和离线验证边界 |

以上内容集中在 [功能、代码架构与流程](01_功能架构与流程.md)，无需分散查早期交付记录。查字段看 [契约](../../reference/contracts.md)，查统计看 [计时](../../reference/timing.md)。

继续读 [P1 基础模块](../P1/README.md)；开始实际运行时看 [P2 主线](../P2/README.md)。
