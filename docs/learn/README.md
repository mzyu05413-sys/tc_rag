# 学习导航

先理解一条主线：文档提供事实，证据解释来源，规则表达要求，测试点描述检查目标，用例给出操作和预期。RAG 查找补充依据，Skill 约束用例表达；一次执行联合导出测试点目录与用例。

## 按你的目标阅读

1. 想先使用：读 [RAG 主线](P2/README.md)，配置、命令、审核和产物都在这里；排错看 [终端交互](P1/13_终端交互与调试.md)。
2. 想先理解：读 [术语与数据流](00_术语与数据流.md)，再读 [P0 基础](P0/01_功能架构与流程.md)。
3. 想看代码：沿 [P1 基础模块](P1/README.md) 理解证据与测试设计，再沿 [P2 模块章节](P2/README.md) 理解向量、索引、检索和评估。
4. 想审核设计及后续计划：读 [架构设计](../design/design_spec.md) 与 [开发指南](../design/dev_guide.md)。

## 阶段地图

| 阶段 | 解决的问题 | 当前边界 |

| [P0 基础](P0/README.md) | 对象、配置、身份、计时与替身 | 基础实现；替身不代表真实模型质量 |
