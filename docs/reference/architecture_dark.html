3数据对象与存储位置

对象产生阶段关键字段
Document / AssetIngestioncontent_hash · relative_path
DocumentBlockPreprocessingkind · heading_path · locator
ChunkChunkingtext · sources[(block,start,end)]
EvidenceSpanExtractionquote · origin · processing_model
Feature / RuleExtraction + Reconcilekind · structured_constraint · status
TestPointPlanningtechnique · objective · applicability
TestCaseGenerationsteps[] · point_ids · status
CoverageLink / IssueValidationstep_no · rule_id · severity
存储内容性质
workdir/data.sqlite全部业务事实、运行与阶段快照、模型调用记录唯一事实源
workdir/assets/<hash>/原始文档与提取图片受管资产
workdir/indexes/向量矩阵、ID 映射、manifest可重建
workdir/output/XMind、Excel、Markdown、JSON派生视图
workdir/diagnostics/诊断运行与回放材料排错
workdir/local.yaml本机配置与密钥引用不入库
  • 视图（Excel/Markdown）不反向修改事实；导出失败可只重建，不重跑模型。
  • 向量索引与模型版本、维度、归一化方式绑定；换模型需要重建。
  • vision / OCR 证据与原文证据通过 origin 严格区分，不互相冒充。
