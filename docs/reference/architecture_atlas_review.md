## 仍应明确的边界

- 图 02 的流程编号是讲解步骤，不等于终端阶段数；视觉关闭、恢复执行等会改变实际显示。
- PDF 页检查点是现有能力，不等于 P3 全部可靠运行能力已经完成。
- 图 03 的 rerank 只重排召回前 `rerank_top_n` 项，余下候选保留；失败回退保留召回顺序，不表示证据被判为不相关。
- rerank 随上层批次并发，当前没有独立的重试 / 并发器；不要把端点通用 `concurrency` 字段当成已生效的独立限制。
- FAISS、关键词召回按配置和可选依赖启用；LangChain / Claude SDK 仅有扩展声明；整页 OCR、关系推断和 API 客户端不能标为已交付。
- 结构校验、词面引文核验、引用闭包与覆盖关联均不能证明业务语义正确。Issue 是混合问题记录数，不等于产品缺陷数；通用语义复核提醒需与具体风险区分。
